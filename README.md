# Chess Site

Built with plain HTML, CSS and JS. Uses chess.js library for user move validation

Hooked up to compiled WASM version of [my c++ engine](https://github.com/shash31/ShashsChessEngine)

## Features:
- Move log and game navigation
- FEN and PGN copy functionality for saving games/positions
- Loading FENs and PGNs
